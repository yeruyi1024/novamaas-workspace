# 手册概览

面向领导审核、平台管理员、星途客户端研发与运维人员，说明星途客户端如何连接 MaaS 平台，以及后台如何配置、发布、追踪和维护公司能力。阅读与接入前请先核对能力状态与平台分支版本。

## 阅读路线

**第一阶段先完成登录接入。** 星途客户端研发优先阅读“接入约定”和“登录接入（第一阶段）”，跑通登录、读取当前账号、刷新登录状态和退出。套餐、托管密钥、模型对话及插件技能属于后续按需接入模块，不是完成第一阶段登录的前置条件。

| 阶段 / 目标 | 阅读章节 | 解决的核心问题 |
|---|---|---|
| **领导审核能力与权限边界** | 本章能力状态矩阵 → 插件更新、停用与排错（管理能力总表） | 哪些能力已实现或待审核、哪些内置随客户端发版、哪些由公司后台下发、能否远程更新/停用/删除、是否需要用户确认 |
| **第一阶段：登录接入（当前重点）** | 接入约定 → 登录接入（第一阶段） | 星途如何完成账号密码登录、读取当前账号、刷新短期令牌、安全退出与切号；二次验证与短信登录的待审核边界 |
| **账户、套餐与模型调用** | 套餐与托管密钥 → 模型接口 | 如何查询套餐与订阅、钱包购买确认、获取当前账号托管模型密钥并调用 `/v1` 模型接口 |
| **MaaS 后台配置与发布** | 后台配置与发布 | Root 如何给普通管理员授予模块权限，管理员如何配置连接器、Skill、MCP 并按全部或指定用户发布 |
| **星途拉取目录与回执** | 星途获取插件与技能 | 星途如何拉取连接器、Skill 与 MCP 目录，如何区分推荐、安装与送达/通知回执 |
| **技能包上传、下载与安装** | 技能上传、下载与安装 | 后台如何上传或导入 ZIP 技能制品并确认固定版本，星途如何申请签名地址、校验摘要、安装并回报状态 |
| **日常更新、停用与排错** | 插件更新、停用与排错 | 公司 MCP 统一停用与一键更新规则、连接器与内置能力发版流程、常见错误码与排障核查点 |

仅对接第一阶段登录时，阅读前两章即可开始联调；后四章在对接公司插件、技能与 MCP 管理时按需查阅。

## 能力状态与版本矩阵（领导审核与开发核对必读）

本手册按 2026-10-23 的仓库源码逐项核对。为避免把“规划或局部代码”误认为“已上线可用”，所有能力严格区分四个状态层级：

1. **平台已有接口**：MaaS 服务端源码中存在对应路由与控制器实现。
2. **星途已接入**：星途客户端对应分支已完成主进程与界面层对接。
3. **目标环境已部署**：目标联调或生产服务器已运行包含该接口的后端版本，且完成数据库迁移与配置。
4. **端到端已验收**：已在真实环境中完成平台、客户端、对象存储或计费链路的业务验收。

| 能力模块 | 平台接口状态（MaaS） | 星途客户端接入状态 | 审核、部署与验收状态说明 |
|---|---|---|---|
| **账号密码登录、刷新、当前账号、退出** | 已有接口（`/api/status`、`/api/user/login`、`/api/user/auth/refresh`、`/api/user/auth/logout`、`/api/user/self`） | 已接入（`split/pr2-account-wallet`，`cec45e01`，含工作树会话竞态修复） | **第一阶段主线能力**；真实环境联调需确认 HTTPS/Origin 与刷新 Cookie 策略 |
| **二次验证登录（2FA / TOTP / 短信 MFA）** | 平台源码有 `/api/user/login/2fa`、`/api/user/login/sms/mfa*`，客户端主进程留有适配桩 | **未完成客户端完整接入** | **待审核 / 未实现**：第一阶段不支持；遇到 `require_2fa: true` 须提示暂不支持，禁止当作登录成功或绕过验证 |
| **短信验证码登录（SMS）** | 平台源码有 `/api/user/login/sms/code`、`/api/user/login/sms`（依赖后台开启与短信通道） | 主进程与登录弹窗含短信分支代码 | **待审核 / 开放与验收状态待确认**：不作为第一阶段已交付能力对外承诺；保留接口定义供领导审核 |
| **钱包、套餐查询与余额购买** | 已有接口（`/api/subscription/plans`、`/api/subscription/self`、`/api/user/topup/info`、`/api/subscription/balance/pay`） | 已接入（`split/pr2-account-wallet`） | 购买确认单在客户端本地生成；年包“一次付款、按月发放”及完整扣款对账仍属**待业务验收**事项 |
| **星途托管模型密钥** | 已有接口（`POST /api/apps/starpath/managed-key`，位于 `local/full-platform` `0fd626517`） | `pr2-account-wallet` 已接入；`pr3-extensions` 分支尚未合入该端点 | 依赖 `tokens.managed` 数据库字段迁移；合并 `pr2` 与 `pr3` 的 `maasAuth.ts` 时须保留 `managedKey` 端点 |
| **模型列表与流式对话（正文/思考）** | 已有接口（`GET /v1/models`、`POST /v1/chat/completions`） | 已接入（`split/pr1-conversation-recovery`，`f460f675`） | 仅覆盖文本对话；图片、视频为平台其他能力，星途客户端未接入 |
| **内置连接器展示管理（微信/钉钉/飞书/企微/邮件）** | 已有接口（`/api/apps/starpath/config`、`/admin/config`、`/admin/extensions/connectors`） | 已接入（`split/pr3-extensions`，`f4d596e5`） | 连接器代码内置于客户端安装包；后台仅管推荐展示与排序，**不支持远程热加载新连接器或远程卸载**；客户端读取需启用对应运行开关 |
| **公司 MCP 目录分发、一键更新与统一停用** | 已有接口（`/api/apps/starpath/extensions/mcp` 及管理端草稿/发布/回执接口） | 已接入（`split/pr3-extensions`，含工作树停用刷新修复） | **支持远程统一停用**公司来源 MCP（同步时关闭，不删配置）；更新需用户点击确认 |
| **公司技能（Skill）目录与 ZIP 制品上传/安装** | 已有接口（`/api/apps/starpath/v3/skills/*`、`/admin/skill-artifacts/*`） | 已接入（`split/pr3-extensions`） | **需要用户确认后下载安装**，不支持强制静默升级或远程删除本机已装技能；OSS 真实上传下载链路待部署环境验收 |

> **部署分支提醒**：`docs/maas-admin-manual` 分支仅提供本手册展示与访问控制。托管密钥（`managed-key`）和扩展管理（`/api/apps/starpath/*`）的后端实现在 `local/full-platform`（核对基线 `0fd626517`）。切勿仅部署手册分支就认为业务接口已就绪。

## 最小接入流程

1. 由部署管理员提供平台根地址 `PLATFORM_URL`，并确认目标后端已部署所需路由与数据库迁移。
2. 客户端读取 `GET /api/status`，确认开放的登录方式（如 `password_login_enabled`）与额度展示参数（`quota_per_unit`、`quota_display_type` 等）。
3. 调用 `POST /api/user/login` 完成账号密码登录，在客户端主进程保存短期 `access_token`、管理 `new_api_refresh` 刷新 Cookie，并记录当前 `session.sid` 与 `user.id`。
4. 调用 `GET /api/user/self` 校验当前登录账号与钱包额度；在部署了托管密钥的平台上调用 `POST /api/apps/starpath/managed-key` 获取专属模型密钥。
5. 使用模型 API Key 调用 `/v1/models` 和 `/v1/chat/completions`；使用登录访问令牌（`ACCESS_TOKEN`）调用 `/api/*` 账户与 `/api/apps/starpath/*` 公司能力接口。
6. 扩展能力接入遵循“先读目录并回报 `catalog_received` → 展示新增通知后回报 `notification_shown` → 用户确认后下载、校验、安装并回报 `installations`”，各阶段错误独立处理。

## 示例与变量约定

手册中的所有请求与响应均为脱敏结构示例（字段名、类型与层级严格对齐源码），不是线上抓包或验收报告。`example.invalid`、示例用户 ID、令牌占位符、SHA-256 示例值和时间戳在联调时须替换为实际环境数据。

| 变量占位符 | 含义 | 使用范围 |
|---|---|---|
| `PLATFORM_URL` | 平台根地址，如 `https://maas.example.invalid`（末尾不带 `/` 和 `/v1`） | 所有平台与模型接口 |
| `ACCESS_TOKEN` | 登录或刷新接口返回的短期 Bearer 访问令牌 | `/api/*` 与 `/api/apps/starpath/*` |
| `SESSION_ID` | 登录或刷新接口返回的 `data.session.sid` 会话标识 | 刷新与退出时的 `X-Auth-Session` 请求头 |
| `MODEL_API_KEY` | 托管密钥接口返回的模型调用密钥，与登录令牌严格分离 | 仅 `/v1/*` 模型接口 |
| `MODEL_ID` | 当前账号可用模型的准确 ID（如通过 `GET /v1/models` 获取） | `/v1/chat/completions` |

## 手册访问控制

管理员手册须在平台开启后，由具备管理员权限的账号登录访问。公共 API 文档与管理员手册相互独立：管理员手册正文仅通过受保护的后端接口（`GET /api/admin-manual`）下发，不会打包进前端公共静态资源。若手册入口隐藏或返回 403/404，请先核查当前登录账号角色与后台手册开关，严禁通过放开公共未授权访问来绕过权限检查。

# MaaS 公共页面升级（novamaas.2）

此版本基于 new-api v1.0.0-rc.26，保留 React、TypeScript、TanStack Router/Query、Base UI、Tailwind、Bun 和 Rsbuild。未修改后端业务逻辑、数据库结构、认证机制和管理后台页面。

## 改动

- 保留首页 `Hero → Stats → Features → HowItWorks → CTA → Footer` 顺序及首屏双栏布局，在原组件内部更新视觉和文案。
- 公共展示采用深蓝背景、蓝紫渐变、轻量网点和卡片边框，与仕力嘉 AI 介绍页呼应；支持浅色主题和减少动态效果设置。不增加动画库或外部背景素材。
- 首页改为统一模型服务、应用接入、用量成本与权限管理的 MaaS 表述；能力概览替代固定数量宣传，接口示例移除示例延迟/费用及“200 OK”状态，改为手动选择协议并明确标注演示。
- 模型广场保留真实接口数据、搜索、筛选、卡片/表格、定价单位和详情抽屉；筛选侧栏滚动时为顶部导航预留空间。
- 关于页在管理员未配置内容时显示平台介绍、模型广场入口及仕力嘉 AI 介绍页链接。
- 保留桌面/移动端真实头像菜单及原角色判断，扩大点击区域并增加可访问名称；较窄屏幕采用现有移动导航。
- 移除页脚自动追加的 New API 项目版权角标，保留站点自定义页脚、协议链接和项目源码入口。依据上游 NOTICE，将贡献者声明及上游链接保留在关于页的独立开源信息区域；自定义关于页也保留此区域。上游说明、许可证和源码文件头保留。
- 新增文案覆盖 en、zh、zh-TW、fr、ja、ru、vi 七种语言。

## 部署与验收

使用本次合并对应的 `ghcr.io/yeruyi1024/novamaas-workspace:build_<UTC 合并时间>_multiarch` 镜像，或 CI Summary 中的 digest 地址。不要使用历史 `latest` / `main` 标签。`VERSION` 为 `v1.0.0-rc.26-novamaas.2`，主分支镜像运行版本另带 `-dev.<提交前 12 位>`。

部署后检查：

1. 清空浏览器旧缓存或强制刷新，核对 `/api/status` 的 `version`。
2. 如后台已配置自定义首页，原 HTML、Markdown 或 URL 继续优先生效。需要看新默认首页时，可在站点设置中备份并清空“首页内容”。本次改动不会清空现有配置。
3. 站点名称、Logo 与自定义页脚仍由后台配置；无须改源码设置公司名称。
4. 普通用户和管理员可打开头像菜单进入个人资料/钱包；超级管理员可进入系统设置；控制台入口沿用原导航设置。
5. 检查模型广场搜索、筛选、价格单位与详情是否符合实际渠道配置。

本地浏览器验收使用独立临时 API 测试数据，不连接生产数据库或上游模型，覆盖桌面、390px 手机、820px 平板以及深/浅色展示、头像菜单、模型搜索与详情。镜像是否可启动，由 GitHub Actions 在原生 Linux amd64/arm64 runner 上拉取发布 digest 后验证版本、`/api/status` 和首页 HTML；这不替代部署环境下的真实模型调用测试。

本次提交前已通过 TypeScript 类型检查、39 个测试文件中的 195 项测试、受影响文件的格式检查和生产构建。受影响文件 lint 无错误；自定义页脚沿用上游 HTML 渲染方式，对应既有 `no-danger` 警告仍存在。

# 图片生成实现范围

PC 生图基于 company/main，小程序基于 PC 分支；本分支仅实现图片生成，不新增订阅、支付、视频生成或任务调度。计费与鉴权直接复用公司的 TokenAuth、relay、额度与限流。

## 界面

- PC 左侧提示词、彩色示例、风格、比例与数量，中间当前成品或空画布，右侧可滚动的缩略图合集。
- 默认生图请求只发送 `model` 与 `prompt`，不补齐 `size`、`n` 或 `response_format`；缺省处理复用平台校验和模型默认值。主动选择比例或多图数量时才发送对应字段，参考图仍使用本人素材 ID。
- 生图入口不提供画质选择，也不发送 `quality` 参数；由模型默认值及平台既有渠道配置决定画质。
- 比例选项注明支持情况取决于模型，默认由模型选择尺寸和比例；Seedream 4.5 / 5.0 Lite 的主动比例选项使用符合像素下限的尺寸。
- 右上角配置图片模型与文本模型，各自选择本人现有密钥，展示绑定或继承的分组，加载可用模型。
- 提示词优化直接更新输入框，支持撤销；失败保留原文。
- 任务展示提示词摘要与任务 ID，用户展示用户名与 ID。原图按需加载，列表只返回缩略图。
- 小程序调用同一生图接口，提供本人历史、预览和保存相册，不加入素材库。

## 服务与权限

Router → Controller → imagestudio → 公司现有 relay。生成任务和图片结果只记录元数据，图片对象复用公司现有存储对象台账。

- root 独立控制入口展示、生成调用和 PC 素材联动；配置写入复用现有 root 设置接口。
- 普通历史、删除、密钥、参考图和手动入库只允许本人操作。
- root 在现有管理权限中逐账号授予普通管理员巡查权限；元数据和图片内容分别授权，内容读取留审计。
- 巡查默认全部用户，可筛选指定用户；只读取生成记录，不包含素材库直接上传的图片。
- 生成失败只返回脱敏原因，不保留失败图片或可见历史；上游未接受的失败移除占位任务，已接受的请求保留隐藏幂等元数据，部分成功保留有效图片。
- 同一幂等键只调用一次上游；中断请求不自动重提。删除最后一张图片后隐藏任务并保留防重复计费所需的编号。
- PC 和小程序生成的原图存入公司现有私有 OSS 永久存储，使用独立 `image_studio` 用途及目录，不写入素材库资产或分组；缩略图由 OSS 图片处理生成。
- 普通历史和巡查鉴权完成后才签发图片地址，客户端直接访问 OSS，列表不返回原图或 Base64。老记录保留读取兼容，不在启动时批量迁移。
- root 在现有存储管理中配置永久存储；生成前检查策略、图片类型和凭证，缺失时不调用模型、不计费。上传中断及记录写入失败交给现有清理任务处理；删除生成图片只清理所属生图对象。
- 参考图通过现有素材库上传与鉴权，再签发本人素材 URL；官方 OpenAI JSON 编辑请求转换为 `images: [{image_url: ...}]`，自定义兼容地址维持现有协议，阿里与火山继续使用各自渠道适配。
- 上游成功但 OSS 保存失败时只返回错误、不展示图片；保留隐藏的幂等与计费元数据，重试同一请求不再次调用模型。
- 任务完成状态持久化失败时，事务清理生成结果并标记所属 OSS 对象待删除；处理中只返回任务状态，不暴露尚未提交的图片。
- 手动入库先校验素材联动开关、图片所有者、生成完成状态和素材组归属，再领取保存锁；拒绝请求不会修改图片的保存状态。
- PC 默认只保存生成记录；点击保存并选择本人素材分组后，才调用公司现有素材库接口。删除生成图片保留已入库素材；删除素材也保留生成图片。
- 图片调用复用现有消费日志，生成历史记录任务与图片；不重复创建视频异步任务。日志详情复用公司的“原始请求 / 实际上游请求”展示。
- 原始生图请求与模型映射、渠道参数覆盖后的实际上游 JSON 在发送前存入现有请求快照表，通过请求 ID 关联；只保存输入及素材引用，不保存响应 Base64 或图片副本。沿用每份快照 2 MiB 的限制，快照保存失败不发送上游请求。
- 请求快照带有生图来源标记，原始请求、双请求快照及兼容读取接口均检查图片巡查和内容权限；root 可读，普通管理员须由 root 授权，读取留审计，普通用户日志不返回快照可用标记。删除生成图片不删除审计快照。

## 验证

保留功能开关、归属隔离、管理员授权与撤销、数量边界、请求幂等、失败无入库、本人删除、手动入库重试、独立模型配置、提示词优化与撤销、推荐示例、画质默认与数量选择的回归测试。通过本地模拟上游验证 OpenAI 兼容、火山 Seedream、百度、阿里 Qwen 的默认请求路径、模型映射与响应转换；下载覆盖原图签名、Blob 文件命名、素材删除回退与跨域直链回退。

真实上游画质、真实 OSS 上传与微信真机相册保存仍需对应环境验收；微信后台需要将 OSS Bucket 域名加入 downloadFile 合法域名，PC 下载需在 OSS 配置允许站点域名的 GET CORS。
